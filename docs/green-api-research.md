# GREEN-API: направления оформления

Изучены живые страницы 14 октября 2026 года:

- https://green-api.com/telegram — светлая поверхность, зелёная навигация и основные действия; голубой используется как цвет Telegram. Вычисленные стили основной кнопки: `rgb(59,151,2)` / `#3B9702`, белый текст, радиус 10 px. Типографика — Open Sans.
- https://console.green-api.com/auth — тёмная панель формы, тонкие серые границы, зелёные кнопки с радиусом 6 px. Вычисленный шрифт UI: системный стек с Segoe UI на Windows, размер текста 14 px. Заголовок входа — 24 px. Уведомления и поля из предоставленного пользователем скриншота кабинета имеют ту же спокойную геометрию.

Основной зелёный проверен по computed styles страницы, а не по пикселям скриншота. Логотип взят из опубликованного ассета кабинета: https://console.green-api.com/assets_1.6.13/Logo_GREEN-API.00ec17ef.svg . Макеты не являются официальным продуктом GREEN-API.

## Варианты

- **Светлый кабинет:** горизонтальная шапка, белая боковая панель, почти белая переписка. Умеренная плотность; форма подключения без большого рекламного блока.
- **Тёмный кабинет:** плотная структура консоли, графитовые поверхности, тонкие границы. Зелёный отведён действиям и выбранным элементам; исходящие сообщения приглушены для чтения.
- **Зелёная панель:** навигация и аккаунт собраны в зелёной колонке; переписка светлая. Экран подключения имеет собственную компоновку с зелёной областью слева.

Это три разные компоновки. В каждом макете доступны экран чата и экран подключения. Макеты используют только демонстрационные данные; к API не обращаются.

## Шрифт и стили

Макеты используют системный Segoe UI, соответствующий стеку кабинета. Фактический `C:/Windows/Fonts/segoeui.ttf` проверен через GlyphTypeface: все русские буквы и Ёё присутствуют. Авторские стили находятся в отдельных SCSS-модулях; `main.css` — результат компиляции Sass.
