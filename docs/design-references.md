# Интерфейс и опубликованные референсы

Обновлено 14 октября 2026 года при переходе с MAX на Telegram по запросу пользователя. Компоновка существующего чата сохранена: это смена канала интеграции. Пользовательская библиотека `C:/Users/Rinni/.codex/design-reference-library.md` использована как исследование; её событийные палитры не переносились в чат.

- [Telegram Web A](https://web.telegram.org/a/): просмотрен опубликованный экран авторизации. Тёмная нейтральная поверхность, белый текст и голубой знак самолёта; вторичные действия отделены от основного входа. Переписка без авторизации недоступна. В проекте сохранена существующая светлая тема; самолёт обозначает выбранный канал.
- [GREEN-API Telegram](https://green-api.com/telegram): сервис связывает существующий аккаунт Telegram с инстансом. В приложении GREEN-API обозначает способ подключения, Telegram — канал сообщений.
- [Документация Telegram](https://green-api.com/telegram/docs/): сохранены точные названия `idInstance`, `apiTokenInstance`, `apiUrl`, чтобы поля совпадали с кабинетом. Служебные названия методов не вынесены в пользовательскую переписку.

## Принятые решения

Белые панели занимают основную площадь. Светлый серо-голубой фон отделяет переписку; насыщенный синий используется для основного действия, выбранного чата и исходящих сообщений. Тёплый фон применяется только к предупреждениям, красный — к ошибкам. Значения оттенков подобраны для этого интерфейса и не заявляются официальной палитрой Telegram.

Слева — компактный список переписок, справа — сообщения. На телефоне список и переписка переключаются целиком с явной кнопкой назад. Входящие сообщения белые, исходящие синие; время и статус примыкают к сообщению. В диалоге создания чата доступны номер и @username. Нет вложений, звонков и неработающих пунктов меню.

Системный Segoe UI с резервным Arial: не требует загрузки внешнего шрифта, соответствует рабочему приложению. Фактический файл `C:/Windows/Fonts/segoeui.ttf` проверен через GlyphTypeface: присутствуют все русские буквы А–я и Ёё. Язык продукта — русский. Иконки Lucide используются только для действий и статусов, толщина линий согласована.

Авторские стили разделены на Sass-модули по компонентам, общие токены и базовые правила. Компонентная UI-библиотека не использовалась.
