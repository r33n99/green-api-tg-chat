# Интерфейс и опубликованные референсы

Изучены 14 октября 2026 года. Пользовательская библиотека `C:/Users/Rinni/.codex/design-reference-library.md` прочитана: её решения для событийных страниц не переносились на утилитарный чат.

- [Веб-версия MAX](https://web.max.ru/): просмотрен опубликованный экран авторизации. Светлое поле формы, крупная основная кнопка, спокойная типографика, ограниченный набор действий. Его иллюстрированный голубой фон не перенесён: он не помогает проверять интеграцию. Закрытую переписку MAX без авторизации изучить нельзя; интерфейс проекта не заявляется точной копией MAX.
- [GREEN-API MAX](https://green-api.com/max): чёткое разделение сервиса и мессенджера, функциональное наименование MAX API. В приложении GREEN-API обозначает способ подключения, MAX — канал сообщений.
- [Документация MAX](https://green-api.com/v3/docs/): сохранены точные названия `idInstance`, `apiTokenInstance`, `apiUrl`, чтобы поля совпадали с кабинетом. Служебные названия методов не вынесены в пользовательскую переписку.

## Принятые решения

Белые панели занимают основную площадь. Светлый серо-голубой фон отделяет переписку; насыщенный синий используется для основного действия, выбранного чата и исходящих сообщений. Тёплый фон применяется только к предупреждениям, красный — к ошибкам. Значения оттенков подобраны для этого интерфейса и не заявляются официальной палитрой MAX.

Слева — компактный список переписок, справа — сообщения. На телефоне список и переписка переключаются целиком с явной кнопкой назад. Входящие сообщения белые, исходящие синие; время и статус примыкают к сообщению. Нет вложений, звонков и неработающих пунктов меню.

Системный Segoe UI с резервным Arial: не требует загрузки внешнего шрифта, соответствует рабочему приложению. Фактический файл `C:/Windows/Fonts/segoeui.ttf` проверен через GlyphTypeface: присутствуют все русские буквы А–я и Ёё. Язык продукта — русский. Иконки Lucide используются только для действий и статусов, толщина линий согласована.

Авторские стили разделены на Sass-модули по компонентам, общие токены и базовые правила. Компонентная UI-библиотека не использовалась.
