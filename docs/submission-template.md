# Подготовка к сдаче

Репозиторий: https://github.com/r33n99/green-api-max-chat

Репозиторий создан приватным в аккаунте пользователя. Для проверки работодателем предоставьте ему доступ либо самостоятельно измените видимость. Закрытая публикация Sites также доступна владельцу; без открытия доступа она не является публичным демо для работодателя.

Необходимо дополнить личными данными перед отправкой:

- Резюме PDF и контакт Telegram.
- Предпочтительный формат работы: удалённо / Киров / Химки / Астана.
- При желании — публичная ссылка на демо и скриншоты.
